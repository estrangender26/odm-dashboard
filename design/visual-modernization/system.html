ODM Visual System — Proposal

A single token set reconciling the existing Manila Water / Programs identity with a shadcn-admin-grade surface discipline. Colour is used to communicate; structure is carried by borders and spacing.

Mechanism note for implementation: the reference is on Tailwind v4 with OKLCH tokens in @theme; ODM is on Tailwind 3.4 with HSL custom properties in src/index.css plus tailwind.config.js. The values above port directly; the plumbing does not, and a v3→v4 migration is explicitly not part of this proposal.
